# newsletter-assets

잡스포이즈 주간 뉴스레터에서 사용하는 이미지 자산.

## 사용

이메일 HTML에서 절대 URL로 참조:

```
https://raw.githubusercontent.com/dmus-ai/newsletter-assets/main/<파일명>
```

## 3개월 교체

배경 톤·테마 교체 시 새 주차 경로에 저장하고 commit한다. 실제 발송 HTML은 승인된 커밋 SHA로 고정하여 이후 자산 교체가 이미 발송한 메일의 디자인을 바꾸지 않도록 한다.

## 채용공고 로고 규칙

- 사용할 수 있는 기업 로고는 해당 기업의 공식 사이트에서 다시 확인한 원본을 우선 사용한다.
- 모든 기업 로고는 원본 종횡비를 유지하고, 정사각 투명 캔버스 안에 사방 여백을 둔 뒤 가로·세로 중앙에 배치한다.
- 공식 기업 로고를 구하지 못해 `JOBSPOIS` 로고를 대신 쓰는 경우에도 원본을 위아래 또는 좌우로 늘리지 않는다. 다른 기업 로고와 동일하게 여백을 둔 정사각 투명 캔버스에 중앙 배치한다.
- 주간 자산을 올리기 전에 각 로고의 찌그러짐, 잘림, 중앙 정렬, 여백을 PC·모바일 렌더에서 확인한다.

## 채용공고 표기 규칙

- 상시채용 공고의 마감 표기는 `상시`로 통일하며, D-day 표기와 글자 크기·두께를 동일하게 맞춘다.
- 채용카드의 지역·직무·고용형태는 제목에서 추측하지 않고 원문 또는 주간 입력값을 그대로 사용한다.
- 2026-W42 기준 지역 표기는 밀리하우스 `전남`, 주식회사 윤성물산 `경북`이다.
- 로고를 확인할 수 없는 공고에는 공식 JOBSPOIS 원본 로고를 종횡비 그대로 사용하고, 정사각 투명 캔버스 안에 여백을 두어 중앙 배치한다.

## 승인본과 발송본 일치 확인

- 발송 HTML의 모든 이미지 URL은 승인된 자산이 포함된 커밋 SHA로 고정한다. 로컬 승인 이미지와 공개 URL 이미지의 SHA-256이 다르면 발송을 중단한다.
- 공식 로고 override가 있는 공고는 이전 JOBSPOIS 대체 로고로 되돌리지 않는다. 2026-W42 지하이웰은 GHIWELL 공식 로고(`weekly/2026-W42/job-logo-4.png`)를 사용한다.
- 스티비 저장 후 실제 미리보기의 로고·지역·마감 표기와 이미지 로딩을 확인한다.
- 2026-W42 공통 렌더 이미지는 다른 주차에 영향을 주지 않도록 `imaged-v2/2026-W42/`에 보존한다.

## 레포 정책

- Public (raw.githubusercontent.com URL이 인증 없이 로드되어야 함)
- 민감 정보 없음 (브랜드 자산만)
